## Trabalhos Práticos de Programação e Desenvolvimento de Software I

Os docentes que ministram matérias introdutórias à programação, ofertadas pelo Departamento de Ciência da Computação da UFMG, comumente propõe o desenvolvimento de video games como trabalhos práticos; acredito que porque jogos oferecem ao aluno a oportunidade de conceber a lógica de programação necessária ao game design, e de amadurecer o uso de estruturas como comandos condicionais e de repetição.

### Modo de uso

```bash
cd TP*
gcc TP*.c -o TP*
./TP*
```
, em que '*' é um número inteiro no intervalo [1,2].
